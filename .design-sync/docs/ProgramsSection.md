# ProgramsSection

Seksjon «Ukeprogrammer»: `ModeLegend`, kort per program med minivisning av uken (`DayBar` per dag) og hvilke rom som bruker det; klikk åpner `ProgramEditor`. «+ Nytt program» oppretter via API.

```jsx
<ProgramsSection houseId={houseId} programs={programs} rooms={rooms} onChanged={reload} />
```
