# SonosSection

«Musikk (Sonos)» via Sonos Control API: oppsettstekst uten nøkler, «Koble til Sonos» + lim-inn-felt for adressen etter godkjenning (Sonos krever offentlig HTTPS-redirect), ellers `SonosView`. Oppdateres hvert 15. sekund.

```jsx
<SonosSection />
```
